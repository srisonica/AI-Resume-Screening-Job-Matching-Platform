# AI Resume Screening and Job Matching Platform

This project analyzes resumes and compares them with a job description.

## Planned Features

- Upload multiple PDF resumes
- Extract text from resumes
- Identify candidate skills
- Compare resumes with a job description
- Calculate match scores
- Rank candidates
- Display results in a Streamlit dashboard

## Technologies

- Python
- FastAPI
- Streamlit
- PyMuPDF
- Sentence Transformers
- Scikit-learn

## Project Status

Project in progress.
